# THE CREATOR Governance

This repository follows the evidence-first governance constitution maintained in `elon00/magical-garbage`.

Status values: `PRODUCTION_READY`, `DEVELOPMENT_READY`, `RESEARCH`, `SIMULATION`, `EDUCATIONAL`, `ARCHIVE`, `BLOCKED`.

Production, Solana/on-chain, AI, cryptographic, performance, and security claims require reproducible evidence. Simulations and placeholders must be explicitly labeled. Secrets and private keys must never be committed. Missing evidence is a blocker, not a PASS.

Canonical control plane: https://github.com/elon00/magical-garbage
